# Harness Field Lab

Field-ready Harness sample configurations and learning assets for demos, enablement, and hands-on practice.

## Purpose

This repository is a shared lab space for reusable Harness examples, reference configurations, and lightweight field enablement materials.

The goal is to make it easier to learn, demo, and explain Harness capabilities through practical examples that map to real customer conversations.

## Contents

This repo includes sample assets for:

- Harness pipelines
- Service and environment configurations
- Artifact Registry workflows
- IDP catalog, scorecard, and workflow examples
- CI/CD patterns
- Security and governance use cases
- Reference architecture snippets
- Demo notes and learning exercises

This repo is intentionally lightweight.

Examples should be easy to read, easy to reuse, and tied back to real field conversations.
